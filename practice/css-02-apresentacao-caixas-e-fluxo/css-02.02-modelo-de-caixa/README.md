# CSS-02.02 — Modelo de caixa

[CSS Foundations Lab](../../../README.md) › [Prática](../../README.md) › [CSS-02 — Apresentação, caixas e fluxo](../README.md) › CSS-02.02

A unidade estabelece o modelo de caixa como base para calcular espaço ocupado, relacionando conteúdo, padding, border, margin, box-sizing e colapso de margens.

[![Verificação de conhecimento](https://img.shields.io/badge/Verifica%C3%A7%C3%A3o_de_conhecimento-Abrir-2563EB?style=flat-square)](./knowledge-check.md) [![Evidências práticas](https://img.shields.io/badge/Evid%C3%AAncias_pr%C3%A1ticas-Abrir-16A34A?style=flat-square)](./exercicios/)

## Objetivo

Compreender como as dimensões visíveis e o espaço ocupado por um elemento são formados.

## Conceitos fundamentais

1. content box;
2. padding;
3. border;
4. margin;
5. `content-box` e `border-box`;
6. `box-sizing`;
7. cálculo da dimensão total da caixa;
8. colapso de margens no fluxo em bloco;
9. backgrounds e borders como decoração da caixa.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre mecanismos e resultados que se mostrarem essenciais para compreender **Modelo de caixa**.
