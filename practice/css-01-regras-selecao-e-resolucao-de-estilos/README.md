# CSS-01 — Regras, seleção e resolução de estilos

[CSS Foundations Lab](../../README.md) › [Prática](../README.md) › CSS-01

Este bloco estabelece como regras CSS alcançam elementos e como a linguagem resolve conflitos entre declarações, conectando seleção, cascata, especificidade, herança e valores em um único modelo de decisão.

## Objetivo

Compreender como CSS associa declarações aos elementos e determina quais valores efetivamente participam da renderização.

## Unidades

### [CSS-01.01 — Estrutura da linguagem e aplicação de estilos](./css-01.01-estrutura-da-linguagem-e-aplicacao-de-estilos/)

Compreender a composição mínima de uma folha de estilos e sua relação com o documento.

### [CSS-01.02 — Seletores, relações e estados](./css-01.02-seletores-relacoes-e-estados/)

Selecionar elementos segundo identidade, estrutura, relação e estado sem misturar seleção com comportamento programático.

### [CSS-01.03 — Cascata, especificidade e herança](./css-01.03-cascata-especificidade-e-heranca/)

Prever qual declaração vence quando diferentes regras podem determinar o mesmo valor.

### [CSS-01.04 — Valores, unidades e custom properties](./css-01.04-valores-unidades-e-custom-properties/)

Compreender como valores expressam dimensões, relações e cálculos e como podem ser reutilizados pela própria cascata.
