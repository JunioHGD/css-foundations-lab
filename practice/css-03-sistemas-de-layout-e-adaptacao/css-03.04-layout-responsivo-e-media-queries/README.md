# CSS-03.04 — Layout responsivo e Media Queries

[CSS Foundations Lab](../../../README.md) › [Prática](../../README.md) › [CSS-03 — Sistemas de layout e adaptação](../README.md) › CSS-03.04

A unidade combina adaptação fluida e mudanças condicionais para construir layouts responsivos, usando media queries quando o comportamento do conteúdo e do espaço realmente exige um breakpoint.

[![Verificação de conhecimento](https://img.shields.io/badge/Verifica%C3%A7%C3%A3o_de_conhecimento-Abrir-2563EB?style=flat-square)](./knowledge-check.md) [![Evidências práticas](https://img.shields.io/badge/Evid%C3%AAncias_pr%C3%A1ticas-Abrir-16A34A?style=flat-square)](./exercicios/)

## Objetivo

Produzir layouts que se adaptem ao espaço disponível e às características relevantes do ambiente.

## Conceitos fundamentais

1. layout fluido como comportamento preferencial;
2. dimensionamento relativo e restrições;
3. Flexbox e Grid responsivos;
4. media queries;
5. media features;
6. consultas por largura, altura e orientação;
7. range queries;
8. breakpoints determinados pela necessidade do layout;
9. estratégias mobile-first e suas limitações;
10. combinação entre adaptação fluida e mudanças condicionais.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre mecanismos e resultados que se mostrarem essenciais para compreender **Layout responsivo e Media Queries**.
