# CSS-03 — Sistemas de layout e adaptação

[CSS Foundations Lab](../../README.md) › [Prática](../README.md) › CSS-03

Este bloco organiza os principais sistemas de layout a partir do problema que cada um resolve, desenvolvendo escolha consciente entre fluxo, posicionamento, Flexbox e Grid e adaptação responsiva orientada pelo espaço disponível.

## Objetivo

Aprender a escolher e combinar os sistemas modernos de layout em vez de utilizar posicionamento ou propriedades isoladas como soluções genéricas.

## Unidades

### [CSS-03.01 — Eixos, alinhamento e escolha do mecanismo](./css-03.01-eixos-alinhamento-e-escolha-do-mecanismo/)

Reconhecer o problema de layout antes de selecionar a ferramenta que irá resolvê-lo.

### [CSS-03.02 — Flexbox](./css-03.02-flexbox/)

Construir layouts em que a distribuição e o alinhamento ocorram principalmente ao longo de um eixo.

### [CSS-03.03 — Grid](./css-03.03-grid/)

Construir layouts nos quais linhas e colunas precisam ser controladas conjuntamente.

### [CSS-03.04 — Layout responsivo e Media Queries](./css-03.04-layout-responsivo-e-media-queries/)

Produzir layouts que se adaptem ao espaço disponível e às características relevantes do ambiente.

## Checkpoint

O checkpoint verifica a capacidade de reconhecer problemas de layout, justificar a escolha entre fluxo, posicionamento, Flexbox e Grid e combinar esses mecanismos com adaptação responsiva orientada pelo conteúdo e pelo espaço disponível.
