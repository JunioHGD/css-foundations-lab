# CSS-04.01 — Acessibilidade visual e de interação no CSS

[CSS Foundations Lab](../../../README.md) › [Prática](../../README.md) › [CSS-04 — Robustez, acessibilidade e organização](../README.md) › CSS-04.01

A unidade relaciona decisões de apresentação a requisitos fundamentais de acessibilidade, incluindo contraste, foco, legibilidade, zoom, reflow, ordem visual e preferências de movimento.

[![Verificação de conhecimento](https://img.shields.io/badge/Verifica%C3%A7%C3%A3o_de_conhecimento-Abrir-2563EB?style=flat-square)](./knowledge-check.md) [![Evidências práticas](https://img.shields.io/badge/Evid%C3%AAncias_pr%C3%A1ticas-Abrir-16A34A?style=flat-square)](./exercicios/)

## Objetivo

Estilizar interfaces sem remover ou prejudicar informações e mecanismos de interação necessários ao usuário.

## Conceitos fundamentais

1. contraste de texto e componentes;
2. informação não transmitida exclusivamente por cor;
3. foco visível;
4. foco não obscurecido por elementos sobrepostos;
5. legibilidade e espaçamento textual;
6. redimensionamento de texto;
7. zoom e reflow;
8. prevenção de overflow horizontal desnecessário;
9. ordem visual versus ordem estrutural;
10. preservação da ordem de navegação;
11. movimento e `prefers-reduced-motion`;
12. media queries relacionadas a preferências do usuário.

## Síntese

Esta seção será consolidada após a conclusão da unidade, registrando de forma objetiva os modelos mentais, relações entre mecanismos e resultados que se mostrarem essenciais para compreender **Acessibilidade visual e de interação no CSS**.
