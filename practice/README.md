# Prática e Evidências

Esta seção organiza a documentação e as evidências selecionadas do Lab segundo a mesma progressão definida pelo currículo. Cada bloco apresenta suas unidades e encerra com um checkpoint de validação cumulativa.

## Blocos

### CSS-01 — Regras, seleção e resolução de estilos

Este bloco estabelece como regras CSS alcançam elementos e como a linguagem resolve conflitos entre declarações, conectando seleção, cascata, especificidade, herança e valores em um único modelo de decisão.

[Explorar bloco →](./css-01-regras-selecao-e-resolucao-de-estilos/)

### CSS-02 — Apresentação, caixas e fluxo

Este bloco desloca o foco da resolução de estilos para o resultado visual e espacial: texto e cor, formação das caixas, fluxo, dimensionamento, posicionamento e empilhamento passam a ser analisados como mecanismos relacionados.

[Explorar bloco →](./css-02-apresentacao-caixas-e-fluxo/)

### CSS-03 — Sistemas de layout e adaptação

Este bloco organiza os principais sistemas de layout a partir do problema que cada um resolve, desenvolvendo escolha consciente entre fluxo, posicionamento, Flexbox e Grid e adaptação responsiva orientada pelo espaço disponível.

[Explorar bloco →](./css-03-sistemas-de-layout-e-adaptacao/)

### CSS-04 — Robustez, acessibilidade e organização

Este bloco consolida CSS como parte de uma interface robusta: preserva acessibilidade visual e de interação e organiza a cascata para que estilos permaneçam previsíveis, reutilizáveis e capazes de evoluir.

[Explorar bloco →](./css-04-robustez-acessibilidade-e-organizacao/)
