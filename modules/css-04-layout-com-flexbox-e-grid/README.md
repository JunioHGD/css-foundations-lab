# CSS-04 — Layouts com Flexbox e Grid

Construir layouts modernos escolhendo corretamente entre distribuição unidimensional e bidimensional.

## Conteúdos

- **CSS-04.01 — Flexbox**
- **CSS-04.02 — CSS Grid**

## Competências

- Escolher Flexbox ou Grid em função das dimensões do layout.
- Controlar alinhamento, distribuição e preenchimento disponível.
- Criar uma estrutura de página legível sem truques de posicionamento absoluto.

## Exercício integrador

**Dashboard em Grid e Flexbox.** Construir um painel simples de informações com cabeçalho, navegação, cartões e área principal.

**Validação:** Aplicar Grid ao arranjo principal e Flexbox a componentes internos. Manter alinhamentos previsíveis quando o conteúdo muda. Justificar a escolha de cada mecanismo de layout.

O exercício será publicado neste módulo após a conclusão dos estudos.
